# Lo

A tiny Minecraft-style voxel sandbox that runs in the browser.

## Play locally

```bash
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Controls

- Click the screen to lock the mouse and look around
- `WASD` to move
- `Space` to jump
- Left click to break a block
- Right click to place the selected block
- `1`-`5` to change block type
- `R` to reset the world
